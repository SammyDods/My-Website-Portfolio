rooms4rent

full-stack rental platform

rooms4rent is a full-stack web application that connects landlords and renters in a simple, streamlined platform. Landlords can post and manage property listings, while renters can browse available rooms, submit applications, and leave reviews after their stay.

My Contribution

Built the user profile functionality across the React frontend and Go backend, working with PostgreSQL and MongoDB for profile data and integrating the frontend with the REST API.

Features

  • User authentication with roles: Renter, Landlord, or Both
  • Landlord dashboard with listing management
  • Renter dashboard with recommended and previously viewed properties
  • Applicants view for landlords
  • Profile customization with profile pictures and bio
  • Responsive UI built with React

Tech Stack

  • Frontend: React, CSS
  • Backend: Go (Golang)
  • Database: PostgreSQL, MongoDB
  • Containerization: Docker
  • API: REST with JSON

Source and hosted demo are currently private — built as a capstone with Docker Compose (frontend, Go backend, PostgreSQL, and MongoDB).
