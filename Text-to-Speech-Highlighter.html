Text-to-Speech Highlighter

from concept to launch

Developed a Chrome extension at EngHacks 2022 that provided text translation and text-to-speech capabilities across websites, supporting language learners and users with reading difficulties. The extension used JavaScript with Microsoft's Azure Translation and Language Detection APIs and grew beyond the hackathon to reach 10,000+ users and over 4 million API calls per month on the Chrome Web Store.

I contributed to the backend integration with Azure's Translation and Language Detection APIs, including the processing and translation of user-selected text.

The project is no longer actively supported, so the Chrome extension may no longer function.
